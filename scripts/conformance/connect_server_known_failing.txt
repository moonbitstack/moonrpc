# The server half's known failures: every `Deadline Propagation` permutation over TLS.
#
# The suite drives 48 RPCs at once and gives each one 2 seconds. A TLS handshake costs one
# RSA-2048 private-key operation, which this stack performs in pure MoonBit, in constant time:
# measured at 0.49 s per signature (`@x509.signature_value` on a 2048-bit key). Forty-eight
# handshakes interleave on the one event loop, so each advances at a forty-eighth of the CPU
# and the first finishes around 24 s — long past the deadline the case sets. The same cases
# pass when the suite runs with `-p 1` (140/140), and every other TLS case in the suite passes
# at full parallelism: the server's TLS is correct; its RSA throughput is not forty-eight
# handshakes in two seconds.
#
# That is a property of the crypto stack, not a bug here, so it is declared rather than
# skipped: the runner still runs all seventy, and fails the build if one starts passing
# without this list being updated.

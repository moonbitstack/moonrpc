The engine, in your browser tab

This page loads the real moonrpc library, compiled to JavaScript — the same H2Client and H2Server from the homepage, running in memory, no server. Encode a message, pick a call kind, and read back every frame the two engines trade.

The compiled engine (docs/engine/moonrpc.js) did not load. Build it with moon build --target js ./src/examples/browser/moonrpc-demo and refresh.
